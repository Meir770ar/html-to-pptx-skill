# שדרוג מצגת קיימת ללא שינוי התוכן

## גבולות העריכה

זהו מסלול עיצוב על עותק של המקור. הטקסט, הנתונים, הערות המרצה, סדר השקופיות, מזהי האובייקטים, הקישורים ומקורות המדיה נעולים. תוכנית העיצוב מאפשרת פונט, גודל, צבע, משקל, רקע, גבולות ומיקום/גודל של אובייקטים נתמכים. אפשר להוסיף גם מלבנים/אליפסות דקורטיביים ללא טקסט או מדיה, למשל קו דגש. שינויים בתוכן נדחים; אין דגל שמדלג על בדיקת השימור.

יש שלוש ערכות בסיס: `editorial`, `business`, `midnight`. הן נקודת התחלה, לא תחליף לשיקול עיצובי. `--layout=preserve` שומר מיקומים וגדלים; `--layout=auto` מסדר מחדש רק שקופיות פשוטות עם שני אובייקטי טקסט, ללא רכיבים אחרים או רקע תמונה. לשקופיות אחרות, הסוכן מכין תוכנית מדויקת אחרי קריאת התוכן ורינדור המקור. אין לבצע סידור אוטומטי של תרשימים או קבוצות מורכבות.

```bash
node scripts/redesign-pptx.cjs inspect source.pptx source.pptx-work --preset=editorial --layout=auto
```

הכלי יוצר מלאי של התוכן וההערות, מיקומים ומזהי אובייקטים ותוכנית `design.redesign.json` הקשורה ל־SHA-256 של המקור. `inventory.html` הוא מלאי לקריאה, ולא הדמיה של עיצוב המצגת. מקור PPTX חדש מחייב תוכנית חדשה.

## תכנון ועיצוב

רנדרו את המקור באמצעות `verify-powerpoint.ps1` כשיש PowerPoint, או השתמשו בכלי המצגות של הסוכן. בדקו את כל השקופיות לפני שינוי כולל. חלקו את האובייקטים לתפקידים לפי תוכנם בפועל: כותרת, הסבר, ראיה, תמונה, טבלה, נתון מרכזי, הערת שוליים. השתמשו באובייקטים הקיימים ובמזהים שלהם; אין צורך לחלץ ולכתוב שוב את הטקסט.

צרו פריסה שמשפרת היררכיה, ריווח, קריאות, ניגודיות ורצף חזותי. אפשר להעביר תיבה, להרחיב טקסט צפוף, לשנות פונט ולסדר תמונה לצד טבלה. שמרו הדגשות בעלות משמעות, יחידות, תוויות, צבעים בעלי משמעות בנתונים, מיתוג ולוגו שהמשתמש ביקש לשמור. אין להחליף ראיה או תרשים בדקורציה.

```json
{
  "index": 1,
  "background": "F7F4EC",
  "objects": [
    {
      "id": "2",
      "style": { "fontFace": "Arial", "fontSize": 38, "color": "067A74", "bold": true },
      "position": { "x": 1, "y": 0.8, "w": 11, "h": 1.6 }
    }
  ]
}
```

זו דוגמה לסעיף בתוכנית, לא תוכנית להדבקה לכל מקור. קחו את ה־IDs, הממדים ואת `sourceSha256` מן המלאי האמיתי. מיקום נמדד באינצ'ים; גודל פונט בנקודות. רקע תמונה או רקע שמפנה לרפרנס נשאר מוגן. אל תמחקו אותו כדי להחיל צבע חדש.

לשדרוג מהיר לפי ערכה, או לפי פרופיל רפרנס שכבר נותח:

```bash
node scripts/redesign-pptx.cjs restyle source.pptx redesigned.pptx --preset=editorial --layout=auto
node scripts/redesign-pptx.cjs restyle source.pptx redesigned.pptx --style=reference.style-work/design-profile.style.json --layout=auto
```

קבוצות, SmartArt ותרשימים מורכבים נשמרים. נתוני chart, workbooks, masters, layouts, הערות, relationships וכל חלק שאינו שקופית נשמרים בבייטים. לכן כלי זה אינו משכתב את השפה העיצובית הפנימית של רכיבים אלה. מקור סרוק או שקופית שהיא תמונה אחת אינו הופך אוטומטית לאובייקטים לעריכה. קבצים עם macros, חתימה דיגיטלית או מבנה לא נתמך נדחים.

## שער שימור ובדיקה חזותית

```bash
node scripts/redesign-pptx.cjs apply source.pptx source.pptx-work/design.redesign.json redesigned.pptx
node scripts/redesign-pptx.cjs verify source.pptx redesigned.pptx
```

לפני כתיבת הפלט, הכלי משווה תוכן, פסקאות, תבליטים, שדות, מבנה טבלאות, אובייקטים וקישורים, וכן חלקים מוגנים של החבילה. הוא לא ידרוס את המקור. הפלט מקבל דוח `.preservation.json`. אם יש שינוי בתוכן או בהערות — עצרו ותקנו, בלי לאשר את הפלט או לעקוף את השער.

לאחר מכן רנדרו את המקור והפלט והשוו. בדקו שאין חיתוך/חפיפה, טקסט מוסתר, פונט חסר, ניגודיות חלשה, תמונה שנחתכה באופן שפוגע במידע, או צבעי נתונים שאיבדו את משמעותם. כשצריך לתקן, שנו רק את התוכנית והריצו שוב מן המקור. בדיקת טקסט זהה לבדה אינה בדיקת קריאות.

```powershell
./scripts/verify-powerpoint.ps1 -Pptx source.pptx -OutputDir source-office
./scripts/verify-powerpoint.ps1 -Pptx redesigned.pptx -OutputDir redesigned-office
```

## HTML קיים

שמרו עותק לפני העריכה. שנו CSS, פריסה, טיפוגרפיה ומושן תוך שמירת הטקסט והערות `data-notes`. ודאו שה־export hook מציג את כל התוכן הסופי. השוו לפני מסירה:

```bash
node scripts/content-lock.cjs verify before.html after.html
```

הכלי בודק סדר טקסט מנורמל, הערות מדויקות, יעדי קישורים והפניות למדיה. הוא אינו מבטיח שהבייטים של משאב חיצוני לא השתנו, או שהטקסט שנשאר ב־DOM עדיין נראה היטב. בדיקת דפדפן ורינדור נשארת חובה.
